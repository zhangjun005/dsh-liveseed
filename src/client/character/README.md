# PMX 常驻舞台首版

依赖的设计文档：[网页分工](../../../docs/06-网页角色展示与驱动方案.md)、[模型检查](../../../docs/15-本地角色模型检查与MMD适配.md)、[AIRI 与动作来源](../../../docs/16-AIRI接入与动作来源调研.md)、[HAST 行为控制](../../../docs/17-上身动作与HAST行为控制复核.md)、[完整骨架与表情](../../../docs/18-完整PMX骨架与表情适配方案.md)。实际实现与验收记录见 [19](../../../docs/19-PMX常驻舞台首版与验收.md)。

- `stage.tsx` 注册在 DSH 根级 `shell.overlay`，生命周期独立于工作区、聊天和整理面板；只有模型上方的拖动把手拦截鼠标。`layout.ts` 支持 25%–600% 缩放、上半身构图和负坐标，仅限制把手可达，不强制身体留在页面内。
- `controller.ts` 在舞台和原生设置分类间共享界面状态。只将位置、大小、显示、模型选择和物理开关写浏览器 localStorage，不写 Session / 记忆，也不让模型读写这些状态。
- `renderer.ts` 使用固定版本 `@takahirox/three-mmd` / Three。默认 WebGL2 后端，保留原始 PMX 全骨架、蒙皮、IK、继承、顶点及材质 Morph。单帧只更新一次 helper，`timing.ts` 以时间截止点控制约 60fps，避免刷新间隔取整丢帧；隐藏或页面后台时暂停。放大移出页面时使用相机 view offset，只分配屏幕内可见部分的绘制缓冲。
- `pose.ts` 是当前 PMX 的原生基础预览：呼吸、视线、眨眼以及点头、挥手、侧倾、重心移动、轻摆腿。手臂按实际肢段方向在躯干空间中计算，腕部保持在宽袖外及身体前方，不再用固定 XYZ 角度压低上臂。切换与停止采用输入姿态平滑；在自有 mixer 输入阶段写入，原生求解之后不再覆盖头 / 眼 / 派生骨。
- 程序输入每帧从明确的 authored 基线重算，避免 PropertyMixer 对恒定轨道的缓存使偏移累加。未来 VMD / HAST 接入必须替换为该来源的实际采样姿态，不能把两份输入重复叠上或以求解结果当下一帧基线。
- 原始 Morph 预览逐次覆盖，启用手工预览时停止自动眨眼，以便检查实际单项效果；材质求值和归零由同一个 helper 处理。整体语义表情配方尚未完成视觉校准。
- `physics.ts` 仅在用户启用后加载包内 Bullet WASM，通过同一宿主认证连接提供引擎资源；实际物理在网页 Worker 中运行，主线程初始化仍为库的回退路径保留 Ammo 全局。默认关闭，不能用短时测试承诺全天稳定性。
- `helper.ts` 是固定针对 MMD 0.1.4 的小型性能适配：保持所有原生逐骨物理回写，只在该阶段合并重复的整棵树更新。仅用于单位缩放的当前场景，并在第 1 / 10 / 60 次回写时与未优化算法逐骨比较姿态及 postPhysicsBase；不一致立即恢复原结果，后续回退。更新 MMD 版本时必须复核该适配。
- 模型资源来自宿主 `CharacterAssets`，采用受认证保护的原生 Connection Fetch 路由。目录只读、类型白名单、非目录遍历接口；URL 使用不透明 ID，模型不复制到 dist / public。引擎代码和模型资源走独立的固定入口。

当前未接入 HAST 的 53 骨骼学习底座 / 重定向桥，也没有让聊天输出动作标签或根据整理结果播放。当前范围是可在真实 DSH 中检查的 PMX 执行基线和有限原生动作，不能称作完成了 HAST 移植。

验证：`pnpm check`、`pnpm test:browser`；实际本地 PMX 另运行 `pnpm test:character`，需要 `LIVESEED_DSH_ROOT`。模型截图、原始日志和浏览器产物只写 `.local/character-acceptance-*`。常规 Web 验收明确使用不存在的角色目录，防止其公共合成截图混入本地模型。
