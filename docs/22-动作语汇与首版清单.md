# 动作语汇与首版清单

日期：2026-11-07。状态：**建议稿，待确认**。前置约束：只走 AI 关键帧（手 K）制作；口型 / TTS 不做；不考虑视频动捕与大显存动作生成模型。混合与过渡机制见 [21](21-动作衔接与AI关键帧方案.md)。

## 为什么先定语汇

手 K 的成本几乎全在"每个动作要逐关节摆姿 + 调时长"。先固定需要哪些动作、每个动作的语义与规格，才能判断：哪些值得精细做、哪些只是常驻背景、哪些可以复用同一段动画。否则会先花时间写混合器，却发现动作清单还没定。

## 本模型的可写通道

PMX 实测：493 骨骼、84 Morph（81 顶点 + 3 材质）、368 刚体、10 根「捩」骨、6 根 IK 骨、42 根手指骨（左右各 5 指 × 3 节 + 指尖）。

| 部位 | 可用骨骼 | 说明 |
|---|---|---|
| 躯干 | `センター`、`腰`、`下半身`、`上半身`、`上半身1`、`上半身2` | 身体朝向与起伏 |
| 头颈 | `首`、`頭`、`両目`、`右目`/`左目` | 眨眼与眼球各自独立 |
| 肩臂 | `肩P`→`肩`→`肩+`→`肩C`、`腕`/`腕+`/`腕捩`、`ひじ`、`手捩`/`手捩1-3`、`手首` | 腕捩负责前臂自然扭转，不能只用 XYZ |
| 手指 | `親指0-2`、`人指1-3`、`中指1-3`、`薬指1-3`、`小指1-3` + 指尖 | 手 K 成本高，首版建议只做整手与少量拇指 |
| 腿足 | `足ＩＫ`、`つま先ＩＫ`、`足`/`ひざ`/`足首`/`つま先` | IK 与 D 骨交给 MMD 求解链，手势不要直写 |

硬规则：手势只写声明过的 mask；**不写 IK 骨、D 骨、物理骨**；不写 `両目` 以外的眼球；派生骨不重复求值。

## 一、常驻层（循环，永不"演完"）

| id | 语义 | mask | 周期 | 首版 |
|---|---|---|---|---|
| `breath` | 呼吸起伏 | 上半身1/2、肩、首 | 4–6s | 是（已有雏形） |
| `gaze` | 视线漂移 | 両目、首 | 3–7s 随机 | 是（已有） |
| `blink` | 眨眼 | Morph `まばたき` | 3–5s | 是（已有） |
| `weight-shift` | 重心轻移 | センター、下半身、足IK 小幅 | 8–20s | 是（现有 `weight` 扩成循环） |
| `hair-physics` | 头发 / 裙摆 | 物理骨 | — | 是（MMD 物理，不手 K） |

## 四、腿部（保持不冻结）

| id | 语义 | mask | 说明 |
|---|---|---|---|
| `leg-sway` | 单侧轻摆腿 | 左足ＩＫ（小幅） | 已有，转成关键帧 |
| `knee-soft` | 微屈膝 / 重心下沉 | 下半身、足ＩＫ | 低频，配合 `weight-shift` |
| 不做 | 行走、跑动、坐下、跨场景位移 | — | 陪伴场景不需要，也会引入支撑求解 |

## 五、表情配对（Morph 已有，只做组合校准）

本模型 84 个 Morph 中可直接配对：`照れ`、`脸红`、`まばたき`、`びっくり`、`驚かす`、`喜び`、`笑い`、`困る`、`やっかい`、`じと目`、`慈愛`、`涙`、`汗`、`汗颜`、`怒り` 等。

| 情绪 | Morph 组合 | 身体配合 |
|---|---|---|
| 害羞 | `照れ` + `脸红` | 低头 + 掩口 / 手放胸前 |
| 惊讶 | `びっくり` 或 `驚かす` | 后仰 + 睁眼 |
| 开心 | `喜び` 或 `笑い` | 轻快点头 + 挥手 |
| 为难 | `困る` + `やっかい` | 歪头 + 摊手 |
| 思索 | `じと目` | 托腮 + 移开视线 |
| 不安 | `心配する` | 双手交叠 + 微低头 |

注意：位移型符号 Morph（`汗` / `！` / `？` / `怒`）需要全量强度才可见，预览默认 1.0。

## 六、首版建议范围（12 个）

常驻：`breath`、`gaze`、`blink`、`weight-shift`
反应：`nod`、`shake`、`tilt`、`lean-in`
手势：`wave`、`shrug`、`hands-clasped`、`chin-rest`

理由：这 12 个覆盖"在听 / 回应 / 表达 / 待机变化"四类日常需求，且都不依赖手指细节，手 K 成本可控。其余动作等这 12 个的观感确认后再排。

## 七、单个动作的规格模板

```text
id: nod
语义: 同意 / 表示在听
触发: 用户说话中、回复开始（高频）
mask: ['首', '頭']
时长: 1.0s（0.15 淡入 / 0.30 保持 / 0.55 返回）
幅度: 首约 +4°、頭约 +9°，沿实际肢段方向而非固定 XYZ
缓动: 五次 smoothstep
可叠加: breath、gaze、blink
冲突: shake、tilt（同骨，新动作淡入、旧动作从当前权重淡出）
循环: 否
退出: 淡出回 base
来源: AI 生成初稿 / 人工校准（记录在案）
```

## 八、待确认

1. 这 12 个的首版范围是否符合你要的"温和日常陪伴"；有没有你觉得必须有、但清单里没有的动作。
2. 反应类是否需要更细的频次控制（例如 `nod` 只在用户说话时、`lean-in` 只在长回复时）。
3. 手指细节是否要进首版（42 根手指骨可用，但会让每个手势的手 K 成本明显上升）。
4. 表情配对是否按上表先行；`汗` 这类符号 Morph 是否要作为常态表达（还是只在调试面板保留）。
