# 三轨动作组合与背手待机

2026-11-08。用户认可胸前比心后，要求按手、头、身体及腿部分组并允许组合，继续制作聆听/思索配背手、改善默认手臂、轻踮脚前后晃动。本条覆盖 docs/25 中单片段预览的阶段限制；主线自动调度仍未接入。

## 实现

| 轨道 | 控制范围 | 行为 |
|---|---|---|
| 手 | 双肩、臂、肘、腕、手指 | 背手、比心、挥手等，同轨切换 |
| 头 | 首、頭、両目 | 点头、摇头、思索、聆听等 |
| 身体及腿部 | 躯干、センター、已授权脚部 IK 目标 | 前倾/侧倾、重心、踮脚轻晃等 |

`tracks.ts` 按骨名划分控制域，只认片段中真正变化的轨道，恒定参考键不占用其他组。既有片段数据保持不变，可以选择其中一组，也可作为组合配方同时启动多组。

`NativePose` 由单片段槽改为三轨播放器。不同组可并行，同组切换保留旧姿态样本并在 0.25 秒内淡出，旧新局部增量按同一骨骼的权重混合后应用一次；四元数按同半球归一化混合，避免两个姿态直接相乘。各组可独立停止，持续背手仍有进入、保持及退出。快速连续操作的权重总和会归一化，最终仍恢复当下基线。

### 背手和默认手臂

- 点头、摇头、低头思索再抬眼、侧倾聆听在手轨空闲时自动启动持续背手；如果已有比心等手轨选择，不强行覆盖。背手持续到换手部姿态或明确停止。
- 默认自然站立的手臂在舞台运行时使用更贴身、较舒展的肢段方向，大臂侧张减小，小臂更接近向下。该候选需要用户观察衣服间距，不宣称所有视角均无相交。
- 为保留已验收片段，离线制作基线不改。运行时默认手臂修正随手轨权重淡出；手轨全权播放时使用既有校准基线及原片段增量，停止后回到新自然站立。不是重新生成用户已认可的比心。

### 微踮脚前后轻晃

新增 `tiptoe-rock`，6.4 秒，只有身体组。骨盆微抬、躯干小幅前后协调，双脚 IK 目标抬跟；脚趾 IK 目标按原落点补偿。不直接写 IK 结果骨，不引入物理。

这是一次有限时长的动作，可重复预览；尚无自动常驻循环或随情绪调度。与摇头/点头和任意手轨组合即可。组合时躯干会自然带动头和手的世界位置，三轨独立不等于身体各部分在世界坐标完全不动；接触类和大幅躯干姿态组合仍要看实际观感。

## 设置入口

角色设置按三组列出按钮，当前活动按钮提供按下状态，各组均有停止按钮。“停止片段”停止全部片段。

“组合动作”保留背手前倾、背手歪头，并增加“背手侧倾聆听”。三组中的“侧倾聆听”选择该片段的头部部分；身体组的“身体侧倾”可另行组合；组合区的“背手侧倾聆听”播放完整头部和身体配方，并在手轨空闲时配背手。用户已有手部选择时保留其选择。

推荐验收：保持背手 → 温和摇头 → 微踮脚前后轻晃；再单独换比心，观察摇头/身体是否继续。单独停止身体，手和头不应被停止。低头思索/聆听先在手轨空闲状态点击，验证自动背手。

## 用户复验修订：相对运动与幅度

用户要求三轨必须保持相对运动，并要求晃动更明显、默认小臂与竖直夹角增加 15°且其他默认部位不变。

- 三轨共享原始骨架与父子关系，叠加的是骨骼局部旋转/局部相对位移；不将头、手复制为独立世界空间对象。身体骨变化后，头和手随原骨架继承变换。只有脚部 IK 目标按站立接触需求维护落点。
- 该机制保障骨架连接，不等于已经完成手脸接触约束。托腮和大幅转头等组合仍需专门的接触修正/冲突策略，不应把骨骼不脱节宣传为任何组合都能自然贴合。
- `tiptoe-rock` 前后位移幅度由 `0.025*unit` 增至 `0.10*unit`；三段躯干摆动由 `[.018,.012,-.012]` 增至 `[.060,.040,-.020]` rad，峰值合计约 4.6°。踮脚高度、周期和时长不变。
- 默认小臂沿原水平方位增加相对竖直夹角 15°。实际模型零时刻测得左右均增加 15°，逐骨比较只改变 `右ひじ/左ひじ` 旋转输入，大臂和其他输入未改；手腕/手指随小臂正常继承移动。
- 构建及角色回归 15/15 通过，不截图。
