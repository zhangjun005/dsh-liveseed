## 已确认的方向

- 运行在 DSH 内，不增加独立常驻宿主；专有运行服务与面板不进入普通工作区会话控制面。
- 原生 Session 日志是唯一事实源；跨段日志共同维持同一身份，索引、记忆与叙事可重建。
- L1 积累的自我与关系叙事独立落在 `narrative.md`，由原有整理线反思整合并经提交链更新。它不新增 Context 层或 Agent，与 L0 soul、L2 当日交接、具体记忆及思考来源分开；对应关系见 [12](12-Context内容层级与主线记忆权限.md)。
- 主对话默认按天在安全边界分段，有限交接，不在午夜打断，不完整 fork 全部历史，面板连续。整理线按用户已确认的方案长期保留同一个私有 Session，仍需有界压缩与恢复验证。见 [08](08-长期身份与Session分段.md) 和 [12](12-Context内容层级与主线记忆权限.md)。
- 主线与整理线分开上下文和能力；整理使用 DSH 内配置的 DeepSeek，由代码校验并提交。
- L3 首次召回由检索与组装代码从已提交记忆选择，主线拥有主动只读回想、补查与原话展开权，不需要整理线逐次批准；授权、版本与预算仍由代码检查，不额外增加每轮召回模型。
- 整理线拥有本产品已授权记忆域的完整维护能力，自主整理并经代码提交；不因此获得原始日志改写、任意宿主工具或 soul 自动改写权。用户已确认此权限范围，soul 自动采纳仍未决。
- 主线可提交带来源的叙事理解记录，供后续 L2 承接并由整理线整合进 L1；不直接覆盖 narrative 正文。该分工已获用户确认并接入首版。
- 整理线可自主遗忘，不要求主线先宣告或批准；以温和的日常陪伴为场景基线。
- 不实现独立的情绪 / 关系数值状态模块，状态依赖 context、真实记忆与当前处境。
- 不做复杂记忆管理页，用户可以直接与整理线对话，维护结果仍走受限提交链。
- 初始记忆预留空槽，具体内容后续填；每日首轮的有限交接组装方案已确定，不因初始槽未填而停工。
- 主动表达仅由普通工作区 prompt 接收后的 15 秒窗口触发；情绪线索、连续工作时长只影响窗口内判断，没有固定钟点或达到时长即发言的作息。
- 后台整理、反思、压缩和换段可以独立运行，但不得因完成而直接开口。
- context 压缩不等于主动遗忘；可在原文和补处理任务可靠保存时先压缩，再补整理。
- Live2D / 3D 暂缓，仅保留网页前端接口边界。

## 暂留但不阻塞的内容

- 初始故事材料与叙事：按用户要求仅留导入位置。
- 冷却间隔、连续活动判断的空闲边界、长工作时长阈值、批次与 token 预算：作为可调参数，不增加情绪状态系统。
- 整理的精确 DeepSeek 型号：由宿主有效配置提供。已有可用路由可直接沿用，无须另选 SDK 或提供另一份密钥。
- 物理删除与跨设备等超出当前记忆淡化 / 归档的语义，另行讨论；不因此先做管理面板。

## 主动表达的实现建议，尚未启用


- 15 秒内有新 prompt 时取消旧候选、按最新输入重新计时。
- 冷却或通道占用时跳过当前候选，不在随后某个钟点补发。
- 主动内容落专属会话，前端不抢焦点；轻提示的具体宿主接入待验证。

这些是为满足少打扰与分权原则的实现建议，不把建议自动写成用户逐字确认的要求。
