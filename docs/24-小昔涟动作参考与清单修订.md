## 画面中可核对的姿态

`farewell` 文件是《再见，昔涟》的分镜图，行列从 1 开始。以下是静态姿态观察，不代表完整运动轨迹或常见程度。

| 姿态 | 画面证据 | 陪伴用途与限制 |
|---|---|---|
| 抬手、张开手掌打招呼 | r3c5 | 已有挥手可作为此方向的实现；不声称逐帧复刻原片 |
| 闭眼微笑、双臂轻轻向身体两侧打开 | r3c8 | 可以提炼为舒展、分享喜悦的短动作，不必做大幅展开 |
| 身体略侧向、回望对方 | r2c4 | 提炼为头先转、肩随后轻转，适合从旁观回到注视 |
| 双手收在胸前、微笑 | r4c3 | 安静回应的参考；画面为插画风格，不是现成三维动画；手部靠近时仍需间距校准 |
| 蜷腿坐在树下、手臂靠近身体 | r4c1 | 有生活感，但涉及坐姿、支撑与构图，保留远期参考 |

## 针对用户建议的动作设计

优先建议 `hands-behind-look`，不要仅将此前通用的 `lean-in` 换个名字：

1. 双肩放松，手臂自然向后收，双手停在后腰附近；先不强求十指交握。
2. 上身从髋与躯干分摊前倾，头颈轻微回正，让视线仍落在用户方向。前倾不是低头鞠躬。
3. 可以加小幅歪头，形成停留、观察、等待回应的姿态，再柔和返回。
4. 分成背手保持姿态、前倾进入/保持/退出、歪头与视线三部分，之后可组合；第一版先做一个完整、可中断的片段验证。

以上是根据用户记忆与参考方向作出的制作建议，尚不是已核验的原作关键帧。背手仍存在外套后摆、袖口与手臂的间距风险，不能因为手被遮住就跳过侧后视角检查。

## 清单优先级建议（未冻结）

1. 已确认的内收小臂轻挥手保留。
2. 背手前倾注视作为下一项具有角色辨识度的动作。
3. 小幅歪头、柔和点头、转头再看向用户，作为背手/常驻姿态的可组合反应。它们是设计建议，本轮未为每项找到独立原作镜头。
4. 轻张双臂、胸前收手作为下一批参考。
5. 坐姿、道具阅读、托腮、整理头发继续暂缓。

用户此前提出的默认呼吸状态保留后续事项，本轮没有修改常驻状态、调度或主线表现协议。
