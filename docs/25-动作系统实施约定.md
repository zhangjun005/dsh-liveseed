# 动作系统实施约定

用户已同意记录并继续实施。此文记录设计方向，不能将计划描述为已实现。

## 分工

基础姿态决定自然站立、背手等保持方式；呼吸、眨眼、轻微视线变化作为局部通道。短反应包括点头、歪头、重新注视，可与身体动作并行；争用头颈时必须明确让位。完整动作声明参考姿态、骨骼 mask、进入/保持/退出阶段、可中断时机与返回姿态。

过渡从当前输入姿态衔接，不用上一帧 MMD 求解结果作基线。重复触发不突然归零；涉及身体附近的手臂运动，不能只靠全局淡化保证安全，必要时制作专门过渡。

调度与骨骼播放分开。主线后续只提交受限动作意图，不能生成临时执行代码或写任意骨骼。整理线不触发播放，表现不写回情绪/记忆。聆听/回应是表现语义，不新增持久状态数值；用户普通工作 prompt 后 15 秒仍是主动表达边界。

## 顺序

1. 背手前倾注视：先做手动完整预览，包含进入、停留、返回与停止。
2. 自然站立与背手基础姿态切换、中断、重复播放；背手不要求每次回到垂手姿态。
3. 点头、歪头和视线的局部叠加与冲突处理。
4. 默认呼吸与待机细节。
5. 主线事件接线、频次控制；允许安静停留，不要求每次回复动作。

## 本轮边界

先实现第 1 项的候选，不将其宣传为原作逐帧复刻。参考见 [24](24-小昔涟动作参考与清单修订.md)。保持物理关闭、不改袖骨/材质，真实模型截图只留 `.local`。背手须检查正面与侧后方向，双手先自然靠拢，不强求握指。其余步骤继续作为后续工作。

## 首个候选的落点

`scripts/authoring/calibrate-behind.mjs` 根据本地模型骨骼测点制作 30fps / 4.5 秒的旋转片段，保存为 `behind.generated.ts`。只写双臂、腕、躯干与头颈主控制骨，不写袖骨或手指骨。原有 `wave-small` 数据保持独立。设置→角色新增“背手前倾”按钮，停止走既有淡出。

先收手、再前倾，返回时先收回前倾再放下双臂；手在身后自然分开，指尖放松向下，不做交握。检查曾发现首版双手相互重叠，已调整前臂目标与手腕方向。侧后视角只通过隔离测试中的相机访问检查，没有添加产品调试接口。

新增回归验证首尾一致、各阶段停止后回到当前活动基线（含原有微动），不得以时间 0 的静止姿态误判归位。仍未实现持续保持、基础姿态切换、重复触发连续衔接或完整状态机。

验证：`pnpm check` 17/17 通过；隔离 DSH 加载实际 PMX，正面、侧面、背面与返回截图见本地 `.local/clip-probe-Pfxr4n`。最终背面画面双手分开，未观察到首版的双手重叠。几张截图不构成完整运动无碰撞或长时稳定证明；动作观感等待用户播放确认。

用户反馈前倾不足、需要配合歪头：v2 将躯干分摊的前倾从约 9.5° 增到约 22°，头颈反向补偿俯仰以保持看向用户；前倾后再跟进约 11° 的头颈侧倾。固定时序先在同一个片段内表达，不依赖状态机。后续动作链负责片段之间的组合、条件与衔接，状态机负责何时选择、保持和中断，不能把单片段的协调制作完全推迟到状态机阶段。

v2 验证：`pnpm check` 17/17；实际 PMX 正、侧、背面截图 `.local/clip-probe-2Ewz3P` 已检查。上述角度为制作时局部控制旋转之和，不能当作渲染后全身实测倾角；以用户实际播放感受继续校准。

## 集中验收候选

用户确认 v2 背手前倾后，授权继续制作多个动作集中验收。新增 4 个手动片段，都是自有制作候选，不宣称逐帧复刻原作：

| 入口 | ID | 时长 | 重点 |
|---|---|---|---|
| 背手歪头 | behind-curious | 4.2s | 保持较直的躯干，背手后向另一侧歪头，区别于前倾版 |
| 侧身回望 | side-glance | 3.8s | 肩躯干先轻转，头颈随后回看用户 |
| 轻张双臂 | soft-open | 4.2s | 上臂向下倾斜的轻展开，避免平举成 T 字 |
| 缓点头回应 | gentle-nod | 2.8s | 单次慢点头，带轻微侧倾和躯干配合 |

制作脚本 `scripts/authoring/calibrate-reactions.mjs` 使用本地 `local-rig.mjs`，输出 `reactions.generated.ts`；不会重写已确认的挥手和背手前倾数据。设置里按名称排列，仍可停止。请每个动作结束后再播放下一个：重复触发与跨片段的连续过渡仍属于后续阶段，不能把手动预览当完整调度验收。

回归覆盖各片段首尾参考一致、逐采样角度变化有界、非目标关节不受影响、停止后回到当前活动基线。实际模型各候选的正侧背与停止返回画面只保存 `.local`，不增加物理、表情配方或主线调用。

本批 `pnpm check` 18/18 通过。实际 PMX 的 4 组正面、侧面、背面、停止返回截图位于 `.local/clip-probe-mscyON`；轻张双臂首稿过于水平，已下调上臂与前臂方向后重新生成和复核。完成数值与有限画面检查，动作风格仍待用户集中验收。

## 用户反馈：节奏缺少生动感，暂缓处理

用户认为目前动作呈现匀速运动的感觉、不够生动，明确要求先记录并放着。本次不修改动作数据、插值或时长，也不因这一问题提前引入状态机。

现有制作已使用缓入缓出，故“匀速”先作为观感反馈保留，不直接断言底层全部采用线性角速度。后续需结合实际播放区分：阶段时长过于平均、多个关节同步启停、缺少预备/停顿/跟随/收势，以及循环变化不足。届时先校准单片段的节奏与关节错峰，再处理跨片段编排；不能指望状态机自动补足动作内容质量。

## 剩余工作清单（制作建议，尚未实施）

- 当前已有六个手动片段：内收小臂挥手、背手前倾、背手歪头、侧身回望、轻张双臂、缓点头回应；后四个仍待用户具体反馈。
- 下一批低接触动作候选：温和摇头、低头思索后重新抬眼、轻侧倾聆听。它们是产品制作建议，本次没有新增原作动作证据，不宣称为官方标志动作。
- 默认呼吸/待机：已有微动不等于默认待机表现完成；自然站立与背手保持、视线与眨眼的整体协调仍待制作。
- 重心轻移、腿部小幅摆动：已有程序预览，尚未成为验收通过的正式片段，涉及支撑和 IK 目标，后于上身动作。
- 接触类继续暂缓：胸前收手、手放胸口、托腮、摸头发；双手/脸/宽袖间距校准要求较高。坐姿与带道具动作更后置。
- 非素材工作仍有：基础姿态保持与切换、重复触发和中断的连续衔接、局部轨道冲突、动作链、状态机及主线表现意图接线。此次仅梳理，不一并实现。

## 2026-11-08 用户授权做到“暂缓”一档

本条覆盖上述候选的暂缓状态：用户要求按清单做到接触类这一档，不包含坐姿和道具动作。接触类只需关键帧摆姿与画面校准，不要求物理、运行时碰撞检测或修改袖子绑定。

新制作入口位于设置→角色→动作片段：

| 动作 | ID | 说明 |
|---|---|---|
| 温和摇头 | soft-shake | 小幅左右否定 |
| 低头思索再抬眼 | thoughtful-look | 低头侧看后回看用户 |
| 侧倾聆听 | listening-lean | 躯干侧倾、头颈回正 |
| 保持背手 | behind-rest | 进入后持续保持，停止时播放退出段 |
| 胸前收手 | hands-front | 双手在身前自然靠拢，不强求十指交握 |
| 手放胸口 | hand-on-chest | 单手靠近胸前衣服 |
| 托腮思考 | chin-rest | 单手抬至下巴附近，配合微歪头 |
| 整理头发 | touch-hair | 手移到耳侧，轻微上下梳理 |
| 重心轻移片段 | weight-shift | センター 小幅位移，保持脚部目标 |
| 轻摆腿片段 | leg-sway | 重心预移、左足 IK 目标小幅抬起前后摆、落回 |

默认待机明确为 4.8 秒的轻呼吸，分配到上半身与头颈补偿，继续使用原有眨眼和轻微视线。停止背手后回自然站立；尚未完成跨片段基础姿态过渡、动作链或自动调度。

制作脚本 `scripts/authoring/calibrate-contact.mjs <本地PMX路径>` 在离线利用肢段长度辅助接触摆姿，运行期不执行该求解，输出 `contact.generated.ts` 的旋转和相对位移，不保存模型坐标/网格。既有六个动作片段没有重制或调整节奏，节奏问题继续待办。

位移采样新增 `sampleClipPositions`，按首帧差值叠加，随基线每帧恢复，不能累积偏移。保持片段使用显式 holdAt/releaseFrom；用户停止时从保持姿态进入收势，而非直接重置。手动预览仍建议每个动作结束后再点下一个，重复触发与连续切换尚未完成。

托腮首稿张手挡脸，复核后降低腕部目标并添加右手四指的轻弯曲（主手指骨，非付与输出），不再用张开的手掌遮住眼鼻。此处离线摆姿只辅助生成片段；运行时控制权仍是 restore→authored→clip→原生 MMD，既有物理骨保持不写入。
