## 2 数据流（一页图）

```
外部世界
 对话 ─┐
 时钟 ─┼─→ [M1 感知] ─→ 统一事件 ─→ [M2 记忆·写] ─→ 真相日志
 网页 ─┤                                  │
 屏幕 ─┘                                  ↓
                                   [M3 状态]（数值更新）
                                          │
[轮次触发] ─→ [M5 调度·时机] ─→ [M2 记忆·读] ─→ 组装 L0–L3 ─→ [M4 表达] ─→ 主模型
                                                                  ↓
                                                            格式器/表现调度 → 输出
                                          │
[夜间定时] ─→ [M5 调度·整合] ─→ [M2 记忆·沉淀] ─→ 改写 soul.md / 执行遗忘 / 生成纪事
```

**硬原则**：**投影（L0–L3）必须能从真相日志重建**（§3.8）。做不到就等于没有记忆。

## 3 记忆模块（M2）：唯一现在定架构的模块

### 3.1 职责边界

| 做 | 不做 |
|---|---|
| 存真相（只追加） | 生成台词 |
| 抽取结构化事件 | 决定"什么时候说话" |
| 检索与重排 | 采集外部数据（那是 M1） |
| 沉淀成自我叙事 | 计算情绪（那是 M3，两者协作） |
| 生命周期（强化/保护/衰减/遗忘） | 判断"该不该记"以外的语义（闸门是规则的延伸） |
| 缺席处理 | 视觉/语音 |

**一句话**：记忆模块只回答两个问题——**"她经历过什么"** 和 **"此刻她该想起什么"**。

### 3.2 三层结构：真相 / 投影 / 资源

| 层 | 内容 | 形态 | 谁写 | 频率 |
|---|---|---|---|---|
| **真相层** | 全部事件（append-only） | `events.jsonl` | M1/M4 | 每轮 |
| **投影层** | L1 自我叙事（`soul.md`）、L2 处境、L3 工作记忆 | 文本 + 内存结构 | 夜间整合 / 时钟 / 组装器 | 日 / 轮 |
| **资源层** | 可读取的原文与档案（`memory/<id>`、`day/<date>`） | 文件 + 索引 | 写入路径 | 按需 |

**原则**：投影只放"结论"（三件记得的事、现在的状态），原文留在资源层，**需要时再读**（借鉴 Super-agent 的"局部上下文、按需读取"）。

### 3.3 数据模型（v1）

**Event（真相，不可变）**

| 字段 | 说明 |
|---|---|
| `id` | 稳定 ID（内容哈希或来源 ID，用于去重） |
| `at` | 发生时间（**发送时间**，不是处理时间） |
| `source` | 来源通道：`talk` / `clock` / `web` / `screen` |
| `actor` | 谁：用户 / 她 / 系统；**由通道提供，不由模型自报** |
| `kind` | `message` / `observation` / `system` / `consolidation` |
| `text` | 原文（不删不改） |
| `refs` | 关联（会话、话题、被引用的记忆 id） |
| `meta` | 通道附加信息 |

**MemoryItem（沉淀出的记忆单元）**

| 字段 | 说明 |
|---|---|
| `id` / `kind` | `fact` / `episode` / `preference` / `promise` / `open_loop` |
| `subject` | 关于谁（用户 / 她自己 / 第三方） |
| `content` | 一句可读的事实或经历 |
| `time_range` | 有效时间（开始/结束，支持"曾经"） |
| `importance` | 重要度 0–1（决定是否常驻/是否保护） |
| `confidence` | 置信度（区分"她看到的"与"用户说的"） |
| `provenance` | 来源 Event id 列表（**可回溯**） |
| `lifecycle` | `active / protected / frozen / superseded / archived / deleted` |
| `last_used` / `use_count` | 最近引用与次数（防复述、判衰减） |
| `redact` | 是否"记得但不主动提"（隐私/边界） |

**OpenLoop（未闭合的事）**：`who / what / due_at / status / source_event`——**结构化，不靠自由文本猜**。

**Profile（关系）**：称呼、信任值、禁提列表、关系史里程碑。

**SelfNarrative（`soul.md`）**：她对自己的叙事 3 句、违抗规则记录、版本历史（旧版本不删）。

### 3.4 写入路径（每轮，本地小模型 + 规则）

1. **归一化**：M1 的事件 → Event（补 `source/actor/at`）；
2. **去重**：稳定 ID + 近邻相似度（>阈值视为同一条）；
3. **准入闸门**：值不值得记？（规则 + 本地小分类器）**宁缺毋滥**，低置信进"待确认"；
4. **结构化抽取**：本地 0.5B–1.7B，JSON schema 固定输出（kind/subject/content/time）；
5. **冲突检测**：同实体新事实 → 旧的标 `superseded`（不删除，保留来源）；
6. **落日志**：写 `events.jsonl`（只追加，带 provenance）；
7. **生命周期**：规则触发 `reinforce / protect / weaken / freeze`。

**硬约束**：**主模型不参与写入**（只可"提议"）。写入权在小模型 + 规则。

### 3.5 读取路径（每轮，2–3 条）

1. **查询构造**：当前对话 + 时间 + 状态（不是只用最后一句话）；
2. **召回**：向量 top-20（bge-small）+ 时间窗 + 关键词 + **open_loop 强制召回**；
3. **重排**：本地 cross-encoder → 取 2–3 条；
4. **过滤**：`redact` / 授权表（**检索命中 ≠ 有权提起**）；
5. **组装**：只给"预览 + 路径"，标「可引用，不必提及」；需要全文时按 `memory/<id>` 读。

### 3.6 夜间整合（每天一次，低频高价值 → 建议云端模型）

1. 读当日 events；
2. 聚类 / 合并 / 摘要；
3. **改写 `soul.md`**（2–3 条入叙事；旧版本留档 + 变更记录）；
4. **执行遗忘**：`weaken / forget`，并写出理由（"她决定让它过去"）；
5. 生成**明日纪事**（L2 内容）；
6. 更新 open loop 到期与状态；
7. 写一条 `consolidation` 事件进日志（**可审计**）。

### 3.7 缺席处理（不做容量恢复）

- **不做**"按离开时长恢复 X% 上下文"（判定为过度模拟、易制造扮演感）；
- 只做两件事：L2 一行事实（"距上次 3 天"）+ 夜间纪事里**真实发生过的事**。
- **缺席是内容，不是容量。**

### 3.8 存储与重建

- 结构化：SQLite（memory item / profile / open loop / 生命周期）；
- 事件：JSONL（append-only）；
- 向量：npy 或 sqlite-vec（v1 可先只存关键词 + 时间，向量后置）；
- 自我叙事：`soul.md`（纯文本、人可读、可导出）；
- **重建**：`soul.md` 与所有投影必须能从 events + 整合记录重建；重建结果与当前投影不一致即为 bug。

### 3.9 生命周期动作（借 MaiBot/A_memorix 的词汇）

| 动作 | 含义 | 谁触发 |
|---|---|---|
| `reinforce` | 被再次提及 → 加强 | 读取路径 / 整合 |
| `protect` | 限时保护，不被衰减 | 用户标记 / 规则 |
| `weaken` | 衰减重要度 | 夜间整合 |
| `freeze` | 冻结（保留但不参与召回） | 用户 / 授权 |
| `remember_forever` | 永久保留（"这条我留着"） | 用户标记 / 她自己的决定 |
| `forget` | 移出召回（进回收站，可恢复） | **她的选择**（可验证的宽恕） |
| `supersede` | 新事实取代旧事实（旧的不删） | 冲突检测 |

### 3.10 评测指标（v1 就要能测）

| 指标 | 含义 |
|---|---|
| **精确回溯率** | 提到过去的事，能否指回 event id + 时间 |
| **矛盾率** | 同一实体新旧事实冲突的比例 |
| **遗忘选择正确率** | 该沉的沉了、该留的留了 |
| **注入密度** | 每轮注入的记忆条数（目标 2–3，允许 0） |
| **open loop 到期命中** | 到期的事有没有被提起 |
| **重建一致性** | 投影 vs 从日志重建的差异 |

### 3.11 v1 明确不做

- ❌ 图数据库（关系用字段表达，够用再加）
- ❌ 多级时间恢复（§3.7 已否）
- ❌ 主模型参与写入
- ❌ 会话内压缩（对话短；单次会话超 N 轮再启用）
- ❌ 记忆包导入/合并（v1 只导出）

### 3.12 风险与对策

| 风险 | 对策 |
|---|---|
| 小模型抽取不准 | 宁缺毋滥 + 待确认队列 + 离线对比评测 |
| 记忆库膨胀 | 夜间整合合并 + 生命周期衰减 |
| 投毒（用户喂假信息） | provenance + confidence + 冲突检测；"这是你告诉我的"可追溯 |
| 复述感 | 注入密度 + "可引用不必提" + `use_count` 冷却 |
| 扮演感 | 状态由事件算出（M3），不由 prompt 赋予 |
| 重建失败 | 每晚校验投影可重建；差异告警 |

## 4 其他模块（只写职责概述，不写架构）

**M0 运行时**：单进程优先；负责配置、日志、时钟、持久化路径、崩溃恢复（重启后能从日志接上）。**未决**：是否需要多进程（夜间整合单独进程？）。

**M1 感知**：把外部世界归一化成 Event。v1 只做两个通道——**对话**（用户说的话）和**时钟**（时间流逝、她醒着/睡着）。后置：网页/B站（她"刷到"了什么）、屏幕（她"看到"了什么）。**所有通道都必须提供 `source/actor/at`，不允许模型自报来源。**

**M3 状态**：每轮计算、不持久化为记忆。三个数值：`valence`（好不好）/ `arousal`（兴奋度）/ `trust`（关系深度），由事件更新，**阈值驱动行为**（话多话少、是否主动）。注入时转成自然语言，**不给数字**。**未决**：维度是否够、更新系数。

**M4 表达**：主模型生成 + **格式器**（语气、停顿、动作标记）+ **表现意图队列** + **表现调度器**（独占表达通道，防止多来源抢夺）。原则：AI 只下达语义（说什么、什么情绪、什么动作名），执行层负责资源映射（借鉴 AITuberKit/AIRI）。**未决**：是否上视觉角色、动作集多大。

**M5 调度**：两套、分开——
- **说话时机**：规则门控链（防抖 → 她在忙/睡吗 → 有没有 open loop → 该不该开口），**不交给 LLM**；
- **夜间整合**：固定时刻（如凌晨），一天一次。

**M6 授权**：一张**代码表**，不是 prompt 规则。管三件事：能读什么（哪些通道/哪些记忆）、能主动说什么（时间窗/频率/禁提）、能记录什么（隐私级别）。**prompt 只能表达边界，不能改变边界。**

**M7 交接**：`soul.md` + 关键记忆的可读导出（人类可读、可迁移）。**未决**：导入/合并语义、"换脑"是否在范围内。

**M8 壳**：最小 CLI 或单页；IM/视觉角色后置。**未决**：先做哪个。

**M9 评测/观测**：事件回放（"她为什么这么说"）、**完整 prompt 渲染**（审计喂了什么）、指标看板。**没有这一层，前面所有设计都不可信。**

## 5 横切：本地小模型栈

| 环节 | 用什么 | 本地/云 |
|---|---|---|
| 嵌入 | bge-small-zh-v1.5（项目已有） | 本地 CPU |
| 重排 | 100M–600M 级 cross-encoder ⚑待实测 | 本地 |
| 写入闸门 | 规则 + 小分类器 / 0.5B 模型 | 本地 |
| 结构化抽取 | 0.5B–1.7B，few-shot JSON | 本地 |
| 状态判定 | 规则 + 小分类器 | 本地 |
| **夜间整合** | **云端便宜大模型**（一天一次，质量优先） | 云 |
| 主对话 | 云端 / 本地 1.7B（未决） | 云或本地 |

**原则**：高频低价值 → 本地；低频高价值 → 云端。本地栈总占用 <1.5 GB（主对话在云端时）。
